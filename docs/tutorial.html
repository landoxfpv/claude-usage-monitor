SETUP / 01
Guida all'installazione · 20 minuti

Il consumo di Claude, sempre sott'occhio.

Un piccolo schermo in rete locale che mostra quanto abbonamento Claude hai usato: la sessione da 5 ore, la settimana, le sessioni attive di Claude Code. Si aggiorna da solo, su un Raspberry Pi da pochi euro. Nessun account, nessun token, nessun dato che esce da casa tua.

Cosa ti serve

Un Raspberry Pi qualsiasi (va bene anche uno Zero W usato)
Una microSD da 8 GB o più
Il computer dove usi Claude Code (Mac o Linux)
La stessa rete WiFi per Pi e computer
Raspberry Pi Imager (gratis) per preparare la microSD
20 minuti, la maggior parte dei quali di attesa
STEP 01

Prepara la microSD

Scarica Raspberry Pi Imager e inserisci la microSD nel computer. Poi:

  • Sistema operativo: Raspberry Pi OS Lite (senza desktop, è più leggero)
  • Prima di scrivere, apri le impostazioni (icona ingranaggio): imposta nome host raspberrypi, abilita SSH, scegli utente e password, e inserisci nome e password del tuo WiFi
  • Scrivi la scheda, poi inseriscila nel Pi e collegalo alla corrente
Le impostazioni dell'Imager sono il passaggio che conta: con WiFi e SSH già configurati non ti servirà mai collegare tastiera o monitor al Pi.
STEP 02

Installa il monitor sul Pi

Aspetta un paio di minuti che il Pi si avvii e si colleghi al WiFi. Poi apri il Terminale sul computer ed entra nel Pi via SSH (usa l'utente e la password scelti nell'Imager):

Terminale · sul Pi via SSH
ssh pi@raspberrypi.local

# una volta dentro al Pi:
git clone https://github.com/landoxfpv/claude-usage-monitor
cd claude-usage-monitor
./install-pi.sh

✓ Servizio claude-usage attivo (partirà anche al boot)
Monitor pronto: http://raspberrypi.local:8787

L'installer copia i file, crea il servizio e lo avvia: da questo momento il Pi è pronto e si riavvierà da solo a ogni accensione. Puoi chiudere l'SSH con exit.

STEP 03

Collega Claude Code

Sempre nel Terminale, ma questa volta sul tuo computer (non nel Pi):

Terminale · sul tuo computer
git clone https://github.com/landoxfpv/claude-usage-monitor
cd claude-usage-monitor
./install-client.sh raspberrypi.local

✓ Statusline configurata
✓ Il monitor risponde

Se avevi già una statusline personalizzata in Claude Code, viene conservata automaticamente: continuerai a vederla identica. Se non ne avevi una, ne comparirà una semplice con modello e percentuali di consumo.

STEP 04

Guarda i dati arrivare

Apri http://raspberrypi.local:8787 dal browser di qualsiasi device in casa (computer, telefono, tablet). Poi apri una sessione Claude Code e scrivi qualsiasi cosa: entro pochi secondi il monitor mostrerà le percentuali della finestra da 5 ore e della settimana, con i countdown al reset, e una card per ogni sessione attiva con costo, contesto e righe di codice.

I numeri si muovono solo mentre Claude Code lavora: è l'unico momento in cui il consumo cambia. A riposo il monitor mostra l'ultimo valore noto e i countdown, che restano sempre esatti.
STEP 05

Facoltativo: uno schermo dedicato

La pagina è responsive: su schermi piccoli e bassi (fino a 480×320) passa da sola a una modalità compatta con numeri grandi, pensata per un piccolo display da scrivania collegato al Pi o per un vecchio telefono appoggiato al monitor. Se le sessioni attive sono più di una, ruotano da sole ogni 10 secondi.

Se qualcosa non va

ssh: raspberrypi.local non risponde
Il Pi potrebbe non essersi ancora collegato al WiFi (al primo avvio servono 2-3 minuti) oppure il nome host è diverso. Trova l'IP del Pi dall'app del tuo router (cerca un device "raspberrypi") e usa quello: ssh pi@192.168.1.xx. Controlla anche di aver salvato le impostazioni WiFi nell'Imager prima di scrivere la scheda.
La pagina non si apre
Verifica che il servizio sia attivo: entra nel Pi via SSH e lancia systemctl status claude-usage. Se è fermo, i log sono in journalctl -u claude-usage -e. Ricorda che serve essere sulla stessa rete del Pi.
La pagina si apre ma dice "In attesa del primo dato"
Il Pi è a posto: manca il collegamento dal computer. Rilancia ./install-client.sh <indirizzo-del-pi> e controlla che dica "Il monitor risponde". Poi apri una nuova sessione Claude Code (quelle già aperte potrebbero non ricaricare la configurazione) e scrivi un messaggio.
Vedo "Payload ricevuto, ma senza rate_limits"
La tua versione di Claude Code è troppo vecchia: i dati di /usage nella statusline arrivano dalla v2.1.80. Aggiorna Claude Code e riapri la sessione.
Voglio tornare come prima
Sul computer: apri ~/.claude/settings.json e togli il blocco statusLine (o rimettici il comando che c'era: lo trovi salvato in ~/.claude/usage-monitor.env alla voce STATUSLINE_CMD). Sul Pi: sudo systemctl disable --now claude-usage.
Fatto. Buon monitoraggio.

Il monitor vive su http://raspberrypi.local:8787: niente cloud, niente token, niente manutenzione.
Per i dettagli tecnici, l'API e il setup manuale c'è il README del repo.
